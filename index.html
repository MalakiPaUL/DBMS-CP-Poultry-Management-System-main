Poultry Farm Management System

Run the PHP application in GitHub Codespaces or another PHP-enabled web server. Once the server is running, open the sign-in page to access the dashboard.

Open the sign-in page

Important: This dashboard requires PHP and MySQL. GitHub Pages cannot execute PHP. Open this repository in GitHub Codespaces using the setup described below, or use XAMPP or a PHP/MySQL web host.

Run it in GitHub Codespaces

  1. Push this repository, including its .devcontainer and docker-compose.yml configuration, to GitHub.
  2. On GitHub, open the repository, select Code > Codespaces, and create a Codespace.
  3. Wait for Codespaces to build and start PHP/Apache and MariaDB. The SQL file is imported automatically on first startup.
  4. Open the forwarded app port, then use the sign-in link above.

Run it locally with XAMPP

  1. Install and open XAMPP, then start MySQL.
  2. Create a database named poultry and import the project's poultry.sql file.
  3. From the project folder on Windows, run run-local.bat.
  4. Open http://127.0.0.1:8000/.
