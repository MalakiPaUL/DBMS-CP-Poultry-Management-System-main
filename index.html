Poultry Farm Management System

Use this page as the entry point to the farm management dashboard.

Open the dashboard

You will be taken to the sign-in page first. After signing in, the application opens the dashboard.

Important: This dashboard requires PHP and MySQL. GitHub Pages cannot execute PHP; open this page through a PHP-enabled web server such as XAMPP or a PHP/MySQL web host.

Run it locally with XAMPP

  1. Install and open XAMPP, then start MySQL.
  2. Create a database named poultry and import the project's poultry.sql file.
  3. From the project folder on Windows, run run-local.bat.
  4. Open http://127.0.0.1:8000/.
